# Support

Vantage is maintained on a best-effort basis by volunteers. There is no paid support.

- **Questions and ideas:** open a [GitHub discussion](https://github.com/bhaskarbhaumik/vantage/discussions)
  if discussions are enabled, otherwise a feature request issue.
- **Bugs:** open a [bug report](https://github.com/bhaskarbhaumik/vantage/issues/new/choose). Run
  `vantage doctor` first and include its output.
- **Dossier quality problems** (a wrong fact, a missed source, a verification check that should
  have fired): use the dossier quality issue form. Describe the problem without pasting
  confidential dossier content.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Never use a public issue.

Before asking, check the [README](README.md), the documentation in `docs/`, and
`harness/ARCHITECTURE.md` for how the dossier is designed.
